# 概要
タップ・スライドのかんたんで直感的な操作で歌詞ファイルをかんたんにつくることができます。
現在再生しているメディアから時間を記録するので、アプリに音楽ファイルを挿入する必要はありません。

# 注意
※sdlrcファイルを扱えるのは、**さんとぴメディアコントロールだけ**です。
https://github.com/sandolpin/SantopimediaControl3.5

一部のデバイスやandroid15以前のZTEデバイスなど、システムでメディアコントロールを扱えないデバイスでは、ご利用いただけません。
このアプリが使えるかどうかは、さんとぴメディアコントロールを利用し、アルバムアートや時間表示、操作ができるかをたしかめてからご利用ください。
